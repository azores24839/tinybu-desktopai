# TinyBu UX 优化修改说明

日期：2026-06-22

状态：需求基线，等待逐项讨论与执行规划。

## 0. 本轮优化目标

请基于当前 TinyBu 项目做一轮 UX 信息架构、主路径和页面文案优化。不要大规模重构底层数据结构，优先调整用户可见的信息架构、命名、首页结构、练习闭环、复盘保存流程、表达库入口、截图后的即时任务，以及 Settings 页面分层。

本轮目标不是把 TinyBu 做成更完整的素材管理系统，而是让它更像一个清晰、轻量、可信的桌面 AI 外语表达伙伴。

核心体验目标：

用户可以从真实内容、截图、网页选文、YouTube 字幕、自由输入话题或历史表达出发，快速生成一次可以开口的练习任务，并在练习后获得适合自己水平的表达优化建议，保存到表达库，之后可以继续复用。

产品当前界面语言先统一为中文。注意：这不代表产品定位只写成“中文学英文”，而是当前系统 UI 使用中文，目标语言默认是英文，未来仍应保留拓展到其他语言的可能性。

## 1. 核心主路径调整

当前主路径应从偏工具化的：

```text
Capture → Inbox → Topic → Study Room → Practice → Review
```

调整为用户更容易理解的：

```text
选择练习任务
→ 准备
→ 开口练习
→ 练习复盘
→ 保存表达
→ 表达复用
```

用户不需要先理解 Capture、Suggested Group、Topic、Study Room 等内部概念，才能开始练习。首页和桌面伙伴都应该优先帮助用户完成一次轻量练习。

核心闭环：

```text
找到或导入内容
→ TinyBu 生成口语任务
→ 用户准备
→ 用户和 TinyBu 练习
→ TinyBu 根据用户水平复盘
→ 用户保存有价值表达
→ 表达库支持之后复用和造句
→ 学习记忆生成下一次推荐
```

## 2. 信息架构调整

主导航建议保留 6 个一级入口：

```text
今日练习
收集箱
练习话题
表达库
学习记忆
设置
```

对应关系：

| 当前概念 | 新用户侧名称 | 处理方式 |
| --- | --- | --- |
| Home | 今日练习 | 主入口 |
| Inbox | 收集箱 | 保留，但降低工具感 |
| Capture | 保存内容 / 素材片段 | 不作为一级概念暴露 |
| Suggested Groups | AI 整理建议 | 作为收集箱里的辅助建议，不作为主概念 |
| Needs Review | 待确认 | 用户化命名 |
| Unsorted | 未整理 | 用户化命名 |
| Topic | 练习话题 | 保留 |
| Study Room | 读懂一下 | 作为练习话题内的辅助准备环节 |
| Practice | 开口练习 | 保留 |
| Practice Review | 练习复盘 | 保留 |
| Archive | 保存表达 | 合并到复盘页，不单独作为页面 |
| Notebook | 表达库 | 改名，强调可复用表达 |
| Bu’s Memory | 学习记忆 | 保留独立页面 |
| API Settings | 高级 AI 设置 | 放到 Settings 折叠区域 |

## 3. 首页：从 Dashboard 改为“今日练习任务中心”

首页不是普通聊天入口，也不是完整学习 Dashboard，而是“我现在可以练什么”的任务中心。

首页建议分为 4 个区域。

### 3.1 今日推荐练习

主卡片展示一个最推荐的练习任务。

示例结构：

```text
今日推荐练习

话题：聊聊你最近保存的 AI 产品文章
目标：用英文表达你的观点，并说明理由
适合：中等难度 / B1-B2
来源：你刚保存的网页内容

[开始练习]
[先读懂一下]
```

注意：

- 不要写“30 秒准备”。
- 准备环节就叫“准备”。
- 不要给用户紧迫感。
- 任务预计时长可以弱提示，但不要作为主标题，例如“约 3–5 分钟”。

### 3.2 刚保存的内容

首页需要承接浏览器扩展、桌宠、小黑岛、截图识别的内容。

示例：

```text
刚保存的内容

你刚保存了 3 条内容，TinyBu 可以帮你变成口语任务。

- YouTube 字幕：AI tools for designers
- 网页选文：remote work discussion
- 截图文字：presentation feedback

[用这些内容练习]
[查看收集箱]
```

目标是避免用户保存内容后只能进入 Inbox 整理。保存内容后应该可以直接 Practice。

### 3.3 自由输入话题

保留自由输入，但作为次级入口。

示例：

```text
想聊别的话题？

输入一个你想练习的内容，TinyBu 会帮你生成一个口语任务。
[输入框]
[生成练习]
```

### 3.4 学习记忆轻提示

首页可以有一个小角落展示学习记忆生成的推荐依据，但不要抢主任务视觉。

示例：

```text
TinyBu 记得

你最近常练 AI / design 话题，
表达原因时容易停顿。
今天可以试着练习：
“用两个理由解释一个设计选择。”
```

点击后可进入“学习记忆”独立页。

## 4. 截图 / 识图后的即时任务 Flow

截图识别后不要只进入收集箱。用户可能只是想快速理解，也可能想立刻练习。

截图识别完成后提供两个主要动作：

```text
识别完成

TinyBu 已经读到了这段内容。你想怎么用它？

[问问这是什么]
[用它练口语]
[保存到收集箱]
```

### 4.1 快速理解路径

适合用户只是想理解截图内容。

```text
截图 → OCR / 识别 → Ask about this → TinyBu 回答 → 可继续追问
```

界面按钮：

```text
[问问这是什么]
[解释重点]
[帮我总结]
```

### 4.2 练习路径

适合用户想把截图内容变成口语任务。

```text
截图 → OCR / 识别 → 生成练习任务 → 准备 → 开口练习 → 练习复盘
```

界面按钮：

```text
[用它练口语]
```

生成任务时可以显示：

```text
TinyBu 可以根据这张截图生成一个练习任务：

任务：用英文解释这段内容的重点
目标：说清楚它在讲什么，并补充你的看法

[开始准备]
```

## 5. 准备页优化

准备页名称统一为“准备”，不要叫“30 秒准备”。

准备页作用不是让用户背句子，而是降低开口压力，让用户知道这次要聊什么。

页面内容：

```text
准备

本次话题
本次任务
你可以从这些方向开始
TinyBu 会怎么陪你练
[开始练习]
```

建议增加一个轻量路径指示：

```text
准备 → 开口练习 → 练习复盘 → 保存表达
```

但视觉要轻，不要像复杂流程条。

## 6. 开口练习页优化

Call 页面继续保持沉浸、低压、少纠错原则。

关键要求：

1. 不要在用户说话过程中频繁打断纠错。
2. 用户卡住时提供提示。
3. 表达优化主要放到练习复盘。
4. 根据用户水平调整 TinyBu 的追问难度和提示粒度。

底部控制建议：

```text
提示
换个问法
字幕
静音
结束
```

如果未来支持文字模式，也可以保留：

```text
[改用文字练习]
```

## 7. 练习复盘：合并保存表达流程

当前 Review → Archive → 表达库的流程过多。请将“选择保存内容”合并进练习复盘页。

复盘页结构建议：

### 7.1 任务完成情况

```text
练习复盘

你完成了本次任务：
用英文表达你对 remote work 的看法，并说明理由。
```

### 7.2 整体反馈

根据用户水平给出低压反馈。

示例：

```text
你已经能表达主要观点。下一步可以让理由更完整，句子之间连接更自然。
```

### 7.3 表达优化建议

不要限制为 3 条。根据本次练习内容动态生成。

默认展示“推荐保存”的表达，数量可以根据内容自动决定。用户可以展开查看更多。

示例：

```text
推荐保存的表达

[✓] I’d put it this way...
用于：换一种更自然的方式表达观点
来自你的原句：I want to say it like this...

[✓] It gives me more flexibility.
用于：表达某件事带来的好处
来自你的原句：It makes me more free.

[查看更多可保存表达]
```

注意：

- 标题不要写“复盘 3 个可改进表达”。
- 不要把数量写死。
- 可以默认推荐一部分，但允许用户查看更多。
- 主按钮为“保存到表达库”。

底部按钮：

```text
[保存到表达库]
[再练一次]
[完成]
```

## 8. 根据用户语言水平适配反馈

这是本轮必须加入的 UX 逻辑。

TinyBu 面向有一定基础的用户，但不同用户水平差异很大。复盘、提示、表达优化都需要根据用户水平分层。

### 8.1 增加用户水平设置

在普通设置中加入：

```text
当前英语水平
- 入门表达：能说简单句，优先保证语法正确
- 日常表达：能表达观点，希望说得更自然
- 进阶表达：希望表达更地道、更准确、更有层次
```

也可以对应：

```text
A2-B1
B1-B2
B2-C1
```

但界面上优先使用用户能理解的描述。

### 8.2 复盘策略按水平变化

#### 入门表达

目标：降低压力，保证能说出来。

反馈特点：

- 少量修改
- 优先语法正确
- 句子短
- 不给长难句
- 不强求高级表达

示例：

```text
你的意思已经清楚了。这里可以把句子改得更完整一点：

原句：I think remote work good.
建议：I think remote work is good for me.
```

#### 日常表达

目标：表达自然，适合真实对话。

反馈特点：

- 优化自然度
- 给常用表达
- 适量补充连接词
- 不堆复杂词

示例：

```text
原句：Remote work makes me more free.
建议：Remote work gives me more flexibility.
```

#### 进阶表达

目标：表达更准确、更有层次。

反馈特点：

- 优化语气、逻辑和表达精度
- 提供更自然或更地道的说法
- 可以给更高级替代表达
- 可以指出语义细微差别

示例：

```text
原句：Remote work is better because it is free.
建议：Remote work gives me more autonomy over how I manage my time.
```

### 8.3 表达库训练也要适配水平

入门用户：

- 重点是看中文能说出简单英文
- 允许更短表达
- 鼓励完成

日常用户：

- 重点是自然替换表达
- 鼓励造句

进阶用户：

- 重点是语境迁移
- 鼓励在不同场景中复用同一表达

## 9. 表达库优化

表达库不是普通收藏夹，而是“下次聊天可以调用的表达素材库”。

页面目标：

```text
我保存过什么表达？
哪些表达今天适合复用？
我能不能用它造句？
我是否已经掌握？
```

表达库页面建议包含：

```text
今日可练
正在学习
需要再用一次
已掌握
```

主 CTA 不要叫“今天复用 3 条表达”。数量可以作为任务指标显示，但标题不要固定数量。

推荐：

```text
今日表达练习
```

或：

```text
练一组表达
```

按钮：

```text
[开始表达练习]
```

卡片结构：

```text
I’d put it this way...

含义：我会这样说 / 我会换个方式表达
适合场景：表达观点、解释想法
来自：上次 remote work 练习
状态：需要再用一次

[练一下]
[标记掌握]
```

## 10. 表达训练流程

表达训练依然可以保留四步，但界面命名需要更自然：

```text
理解含义
→ 判断场景
→ 改写成自己的话
→ 看中文 / 情境回忆英文
```

训练完成后才增加一次训练次数。

训练完成页可以显示：

```text
这条表达已经练过一次。
下次 TinyBu 会在合适的话题里提醒你使用它。
```

## 11. 小黑岛 / 桌宠作为轻量复习入口

可以增加一个轻量方向：用户不必打开完整主应用，也能通过 notch / 桌宠快速复用表达。

这是可行的，但要控制范围。notch 不应该变成完整应用，只作为轻量入口。

建议支持三类轻操作：

### 11.1 快速回顾表达

用户点击小猫或 notch 后弹出：

```text
今天试着用这个表达：

It gives me more flexibility.

意思：它让我更灵活。
试着用它造一个句子。
```

按钮：

```text
[我来造句]
[换一条]
[打开表达库]
```

### 11.2 快速造句

用户输入或语音说一句，TinyBu 给轻反馈：

```text
不错，这句话可以这样更自然：
...
```

### 11.3 快速开始口语对话

定时或用户点击触发：

```text
要不要用上次保存的表达练一小段？
[开始 1 分钟练习]
[稍后]
```

注意：

- 不要强打扰。
- 提醒频率可设置。
- 默认关闭或低频。
- 用户必须能一键关闭提醒。
- notch 只做轻量复习、快速造句和开始练习，不承载完整收集箱、话题管理或设置。

## 12. 学习记忆页面保留独立

Bu’s Memory / 学习记忆保留为独立页面。

但它的价值不只是在页面里展示，还应该影响首页推荐、表达复习、话题建议和 notch 轻提醒。

学习记忆页面可以展示：

```text
你最近常练的话题
你正在积累的表达
你常见的卡点
TinyBu 给你的下一步建议
可编辑的记忆备注
```

首页轻模块可以调用其中一小部分：

```text
TinyBu 记得：
你最近常练 AI / design 话题，
表达原因时容易停顿。
```

notch / 桌宠也可以调用：

```text
要不要练一下上次卡住的表达？
```

## 13. 练习话题 Topic 优化

Topic 保留，但用户侧叫“练习话题”。

Topic 的价值需要更明确：

```text
练习话题不是文件夹，而是一组可以持续练习的表达场景。
```

创建 Topic 时，不要只写“Create Topic”，而是：

```text
创建练习话题
```

AI 整理建议示例：

```text
TinyBu 建议把这 4 条内容整理成一个练习话题：

AI 产品设计表达

之后你可以：
- 围绕这些内容练口语
- 积累相关表达
- 让 TinyBu 记住你的兴趣和卡点

[创建练习话题]
[稍后再说]
```

## 14. 收集箱 Inbox 优化

收集箱保留，但弱化工具感。

顶部分类建议：

```text
全部
刚保存
待确认
未整理
已归档
```

AI 整理建议作为内容卡片或顶部模块出现，而不是独立主概念。

待确认内容的按钮要更用户化：

```text
[确认文字]
[重新识别]
[手动编辑]
[稍后处理]
```

工程文案暂时可以先不大改，但页面结构和命名要先降低工具感。

## 15. Settings 页面优化

本轮先做 UI 布局分层，不需要优先改报错恢复逻辑。

Settings 分为两部分：

### 15.1 普通设置

默认展开：

```text
学习设置
- 界面语言
- 目标练习语言
- 当前英语水平
- 练习偏好

桌面伙伴
- 桌宠模式
- 小黑岛模式
- 复制保存开关
- 提醒频率

权限与数据
- 麦克风权限
- 截图识别
- 本地数据
- 数据清理
```

### 15.2 高级 AI 设置

默认折叠：

```text
高级 AI 设置
- Provider mode
- Chat / learning model
- Screenshot / vision model
- Base URL
- API Key
- Cloud proxy URL
```

普通用户默认不应该一进 Settings 就看到大量模型、API、Base URL、Proxy 信息。

## 16. 全屏练习页的路径感

准备页、开口练习页、练习复盘页、表达训练页都会离开主 Shell，因此需要轻量路径提示，减少用户迷失感。

顶部可以显示：

```text
准备 → 开口练习 → 练习复盘 → 保存表达
```

当前步骤高亮即可。不要做得太重。

结束后需要明确说明用户会回到哪里：

```text
表达已保存。你可以回到今日练习，或去表达库继续练。
```

按钮：

```text
[回到今日练习]
[去表达库]
```

## 17. 优先级

### P0：主路径与首页

- 首页改为“今日练习任务中心”
- 增加今日推荐练习
- 增加刚保存内容模块
- 自由输入变为次级入口
- 学习记忆轻提示放在首页小模块

### P1：复盘与保存表达

- 练习复盘页合并保存表达
- 不再单独跳转 Archive
- 推荐保存表达数量动态生成，不限制为 3 条
- 支持“查看更多可保存表达”
- 保存后进入表达库或回到今日练习

### P2：语言水平适配

- Settings 增加当前英语水平
- 复盘建议根据水平调整
- 表达优化根据水平调整长度、难度和自然度
- 表达训练根据水平调整任务难度

### P3：截图后的即时任务

- 截图识别后提供：
  - 问问这是什么
  - 用它练口语
  - 保存到收集箱
- 支持 Ask 和 Practice 两条路径

### P4：概念命名与信息架构

- 主界面统一中文命名
- Notebook 改表达库
- Bu’s Memory 改学习记忆
- Topic 改练习话题
- Study Room 改读懂一下
- Suggested Group 改 AI 整理建议

### P5：Settings 分层

- 普通设置默认展示
- 高级 AI 设置折叠
- 本轮先做布局，不优先改报错逻辑

### P6：notch / 桌宠轻量复习入口

- 点击小猫 / notch 可以快速回顾表达
- 支持造句
- 支持打开表达库
- 支持开始轻量口语练习
- 不承载完整应用功能
- 提醒低频、可关闭

## 18. 视觉风格保持

保持当前 TinyBu 的视觉语言：

- 米白 / 暖白背景
- 浅网格纹理
- 大圆角卡片
- 黄色作为强调色
- 深色主按钮
- 轻松但不幼稚
- TinyBu 猫咪承担陪伴感
- 不要改成企业后台风格
- 不要把收集箱、设置、AI 配置做得过于工程化

整体体验应该是：

轻量、温和、低压力、有陪伴感，但功能逻辑清晰。
